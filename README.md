# ITForum

Это веб-приложение форума на Java / Spring boot с возможностью регистрировать аккаунты, ролями, категориями.

## Стек:
- Java 17  
- Spring boot 2.7.8
- Безопасность: spring security
- Доступ к базе данных: hibernate
- База данных: postgres

## Возможности:
- **Система аккаунтов:** можно регистрироваться, входить или управлять другими аккаунтами с ролью MODERATOR (по умолчанию аккаунт с такой ролью - admin, пароль - 123)
- **Категории:** посты сгруппированы по категориям в зависимости от принадлежности к какой-либо из них
- **Посты:** опубликовать пост и оставить к нему комментарий сможет любой пользователь, зарегистрировавшийся на форуме
- **Главная страница:** здесь собрана информация, которая может привлечь нового пользователя: недавние посты и самые обсуждаемые категории

## Права доступа ролей:
- **Неавторизированный**: просмотр категорий, постов, комментариев
- **USER**: публиковать посты, оставлять комментарии
- **BANNED**: не может оставлять посты и комментарии
- **MODERATOR**: роли как у USER, дополнительно может создавать категории, управлять другими аккаунтами и удалять посты, комментарии и категории

## Структура проекта:
Controller → Service → Repository → Entity, PostgreSQL, Spring Security

## Запуск:
Запустить можно двумя путями:
1. Через Docker (нужен только сам Docker)
2. Вручную (нужна java 17-й версии и запущенная бд postgresSQL)
