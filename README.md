# ITForum

Это веб-приложение в формате форума, где любой человек может зарегистрировать аккаунт и публиковать посты и комментарии.

**Используемые версии:**  
Java 17  
Spring boot 2.7.8

**Формат хранения данных:** json

**Структура файлов на сервере:**
```
root/
├── springHttp-1.0-SNAPSHOT.jar
├── files/
│   └── json/
│       ├── accounts.json
│       ├── categories.json
│       └── posts.json
```

**Запуск**

1. Установите Java 17 или выше.
2. Скачайте `.jar`-файл из Releases.
3. Создайте структуру директорий для JSON-файлов.
4. Запустите приложение: `java -jar springHttp-1.0-SNAPSHOT.jar`
