# ITForum

Это веб-приложение в формате форума, где любой человек может зарегистрировать аккаунт и публиковать посты и комментарии.

**Используемые версии:**  
Java 17  
Spring boot 2.7.8

**База данных:** postgres

**Что есть на форуме:**
- Аккаунт, можно регистрироваться, входить или управлять другими аккаунтами с ролью MODERATOR
  (по умолчанию аккаунт с такой ролью - admin, пароль - 123)
- Создание категорий (только с аккаунта модератора) и постов (с любого аккаунта)
- Возможность оставить комментарий к любому посту
- Возможность просматривать самые обсуждаемые категории и недавние посты на главной странице,
  а также все категории и посты на соответствующих разделах форума

**Структура проекта:**
Controller → Service → Repository → Entity, PostgreSQL, Spring Security

**Запуск**

1. Скачайте файлы из последнего релиза репозитория.
2. Запустите compose.yaml с помощью docker:
   ```docker compose up -d```
3. Порт - 8080.
